## Dashboard Overview

- **79 Technical References** — Coded into 14 normalized variables
- **91 Directed Relations** — Between variables with influence/dependence scores  
- **3 Functional Groups** — G1: Axial stack, optics, and focal evidence | G2: Fusion, noise, and processing perturbations | G3: Metrics, useful quality, and feasibility
- **Interactive Filters** — Explore by structural class (Driving, Relay/unstable, Dependent, Autonomous), time period (1983–2026), and functional group
- **Relation Network** — Visualize variable dependencies and system couplings
- **Corpus Explorer** — Browse and search references by topic

**Coverage:** 1983–2026 (43 years of literature)

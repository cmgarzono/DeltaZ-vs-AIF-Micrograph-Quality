## Dashboard Features

- **79 Technical References** - Coded into 14 normalized variables
- **91 Directed Relations** - Between variables with influence/dependence scores
- **3 Functional Groups** - Axial stack, Fusion, and Metrics
- **Interactive Filters** - Explore by structural class, time period, and thematic group
- **Relation Network** - Visualize dependencies and couplings
- **Corpus Explorer** - Browse and search references

**Year Span:** 1983-2026
